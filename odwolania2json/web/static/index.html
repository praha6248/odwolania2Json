    Jak to działa
    PDF → tekst (OCR dla skanów) → klasyfikacja → reguły z YAML (+ opcjonalnie LLM) → JSON.
    
      
    
        
      
          
    1. Tekst. Warstwa tekstowa PDF; strony bez tekstu trafiają do OCR (Tesseract lub RapidOCR, CPU).
      2. 
          
    2. Klasyfikacja. Punktacja słów kluczowych z sekcji classify każdego typu. Wynik i dopasowania widać w zakładce „Klasyfikacja”.
      3. 
          
    3. Ekstrakcja. Łańcuchy ekstraktorów (regex, label, keyword_map, …) z normalizatorami. Każda wartość ma zapisane źródło.
      4. 
          
    4. LLM (opcjonalnie). Otwarty model przez API zgodne z OpenAI uzupełnia pola, których nie znalazły reguły.
      5. 
          
    5. Wynik. JSON zgodny ze schematem UZP, nazwany jak plik źródłowy.
      6. 
        
    
        
    Tryb wsadowy: python -m odwolania2json run przetwarza ./input do ./output.
