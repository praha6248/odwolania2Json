Odwołania KIO z PDF do JSON

Wgraj odwołanie, pełnomocnictwo i potwierdzenie przelewu. Aplikacja rozpozna rodzaj dokumentu, wyodrębni dane i pokaże, z którego miejsca w dokumencie pochodzi każda wartość. Działa lokalnie, bez GPU.

Docker i wiersz poleceń

Docker Compose

Interfejs webowy na porcie 8000, foldery input i output zamontowane z hosta.

docker compose up -d
docker compose --profile batch run --rm batch

Python 3.13+

Pliki z input/ trafiają jako JSON do output/ z zachowaniem struktury folderów.

pip install -r requirements.txt
python -m odwolania2json run

Jak zainstalować

1

Pobierz

Instalator dla Windows albo paczkę przenośną dla Windows lub Linuksa.

2

Uruchom

Aplikacja otwiera się w oknie, bez konsoli. Do wiersza poleceń służy odwolania2json-cli w tym samym folderze, np. odwolania2json-cli run.

3

Aktualizuj

Dzwonek w aplikacji pokazuje nową wersję. Instalator zachowuje Twoją konfigurację w config/.
